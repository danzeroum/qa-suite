1Tokens de cor

custom properties · claro e escuro · contraste sobre --papel

Mínimo exigido: AA (4,5:1 para texto). Todos os pares abaixo ficam em ou acima de 5:1 nos dois temas; o texto de cada estado sobre o próprio --fundo-* também (≥ 5:1). Cor nunca é o único canal: forma + rótulo sempre acompanham.

8Regras de implementação

o relatório passa na própria bateria
  1. Arquivo único, zero requisições externas. CSS embutido, ícones SVG inline, favicon em data-URI, system fonts. Nada de CDN, webfont ou analytics. Esta referência: ~68 KB (orçamento: < 300 KB de HTML).
  2. Classes de estado = outcomes verbatim (.passed .failed .xfail .skipped), como o report.py já emite — o template Python interpola direto.
  3. Tema escuro: o mesmo bloco de tokens aparece 2× — sob @media (prefers-color-scheme: dark) e sob :root[data-tema="escuro"] (forçável p/ depuração). No template, uma string interpolada duas vezes. Blocos escuros são @media screen: impressão sai sempre clara.
  4. Sem JavaScript obrigatório: a única interação é <details> nativo. O único script (8 linhas) expande a tabela em beforeprint — progressivo; sem JS o documento continua íntegro.
  5. Impressão é primeira classe: @page margin 15mm · break-inside: avoid em achado, card, nota e linha · âncoras viram texto sem sublinhado · bloco .so-impressao aponta para o summary.json.
  6. Acessibilidade: lang="pt-BR", um único h1, headings sem saltos, landmarks (header/main/nav/footer/section), skip-link "Ir direto aos achados", ícones aria-hidden sempre pareados com rótulo textual, foco visível 2px --acento, tabelas com caption + scope.
  7. Conteúdo vem do código: mensagens detail e a nota epistêmica não são reescritas pelo design — o template as apresenta (serif, 72ch) e apenas destaca referências legais (strong.lei) via regex no gerador. Números pt-BR (vírgula decimal); id de teste nunca truncado.
  8. Pontos de interpolação: {generated_at} {duration_s} {alvo} {comando} · cards de {by_dimension} · achados/alertas/tabela de {results} · inventário de terceiros.json · nota de DIMENSION_NOTES.
